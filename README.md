# ChessGame - Cocos2d-x Card Matching Game

一个基于Cocos2d-x 3.17的卡牌匹配游戏，采用清晰的MVC架构设计。

## ✨ 功能特性

- 🃏 **卡牌匹配游戏**
  - 桌面牌区和手牌区
  - 点数匹配规则（差1即可）
  - 流畅的卡牌移动动画

- 🔄 **撤销/重做功能**
  - 完整的撤销栈
  - 支持重做操作
  - 可扩展的撤销类型

- 📚 **完整的文档体系**
  - 程序设计文档
  - 扩展实施指南
  - 程序阅读指南
  - 快速阅读流程

- 🎨 **清晰的MVC架构**
  - 配置层、数据层、视图层、控制器层
  - 管理器层、服务层
  - 易于维护和扩展

## 🛠️ 技术栈

- **引擎**：Cocos2d-x 3.17
- **语言**：C++11
- **配置**：JSON
- **架构**：MVC + 分层架构


## 🚀 快速开始

### 环境要求

- Cocos2d-x 3.17
- Visual Studio 2019 或更高版本
- CMake 3.26+



## 🎯 核心功能

### 卡牌匹配
- 点击桌面牌区的卡牌，如果与顶部牌点数相差1，则匹配成功
- 点击手牌区的卡牌，可以替换顶部牌

### 撤销/重做
- 点击Undo按钮撤销上一次操作
- 点击Redo按钮重做已撤销的操作
- 支持连续撤销和重做
