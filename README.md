一个基于Cocos2d-x 3.17的卡牌匹配游戏，采用清晰的MVC架构设计。

- 🃏 **卡牌匹配游戏**
  - 桌面牌区和手牌区

  - 易于维护和扩展

## 🚀 快速开始

### 环境要求

- Cocos2d-x 3.17
- Visual Studio 2019 或更高版本
- CMake 3.26+

### 编译运行

```bash
# 1. 克隆仓库
git clone https://github.com/haozhe-qi/ChessGame.git
cd ChessGame

# 2. 使用CMake生成项目
cd build-win32
cmake ..

# 3. 编译项目
打开 ChessGame.sln 并编译

# 4. 运行
运行生成的 ChessGame.exe
```

## 🎯 核心功能

### 卡牌匹配
- 点击桌面牌区的卡牌，如果与顶部牌点数相差1，则匹配成功
- 点击手牌区的卡牌，可以替换顶部牌

### 撤销/重做
- 点击Undo按钮撤销上一次操作
- 点击Redo按钮重做已撤销的操作
- 支持连续撤销和重做
